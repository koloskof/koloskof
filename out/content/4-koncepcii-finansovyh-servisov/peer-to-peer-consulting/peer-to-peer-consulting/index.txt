11:T16a2,<h1>Peer-to-peer Consulting</h1>
<p>Сервис бронирования консультаций с эксператами onair.expert</p>
<p><strong>Раунд: €1M, 11.05.2022</strong></p>
<p>Маркетплейсы экспертов — вещь не новая. Вот только подавляющее их большинство приземляется в конечном итоге на аудиторию стартапов, которые постоянно ищут «экспертизу на целевом рынке» ;-) Как результат, геморроя такие платформы имеют много, а денег — мало. Однако на B2B-рынке есть один общий подход, который можно применить даже тут — и получить возможность зарабатывать гораздо больше. Читать дальше: https://fastfounder.ru/ne-razmenivatsja-po-melocham/</p>
<p><strong>Продукт</strong></p>
<p>Какую проблему(-мы) вы решаете?</p>
<p>Пойска ведущих экспертов  Прокачка продуктовых навыков с лидами команд: менеджерами, аналитиками, дизайнерами, разработчикам</p>
<p>У кого эта проблема возникает? (кто ваши клиенты?) [сегмент пользователей]</p>
<ul>
<li>У основателей стартапов, которые ищут Адвайзеров с продуктовой экспертизой</li>
<li>У менеджеров, которым нужен консультант в отдельно взятой области</li>
<li>У специалистов которым нужен ментор чтобы подтянуть навыки в определенной дисцину</li>
</ul>
<p>Как они решают свою проблему сейчас?</p>
<ul>
<li>Спрашивают коллег из своего окружения</li>
<li>Копают информацию из свободных источников (записи лекций / публикации)</li>
</ul>
<p>Кто ваши прямые конкуренты?</p>
<ul>
<li>Calendly <a href="https://ershov.io/dsprogram">https://ershov.io/dsprogram</a></li>
<li>Конструкторы посадочных страниц <a href="https://ershov.io/dsprogram">https://ershov.io/dsprogram</a></li>
</ul>
<p>Как ваш продукт поможет решить их проблему? (аргументы)</p>
<ul>
<li>Мы предлагаем One Stop Solution для прокачки продуктовых навыков</li>
</ul>
<p>Чем отличается от других продуктов представленных на рынке? (аналитическая информация)?</p>
<ul>
<li>Качественное комьюнити проверенных экспертов</li>
<li>Прямая интеграция с платёжной системой для бесшовной оплаты консультаций</li>
</ul>
<p><strong>Пользовательский опыт</strong></p>
<ul>
<li>Как пользователь попадает в сервис?</li>
<li>Какие у них цели?</li>
<li>Какие ключевые сценарии?</li>
<li>Что происходит на каждом из этапов?</li>
<li>На каких основных моментах вы фокусируете пользователя?</li>
<li>Что мы хотим чтобы пользователи почувствовали в процессе взаимодействия?</li>
</ul>
<p><strong>Маркетинг</strong></p>
<ul>
<li>Как ваш продукт будет поставляться на рынок? (через какие каналы).</li>
<li>Как устроена ваша воронка продаж? (основные этапы)</li>
</ul>
<p><strong>Финансы</strong></p>
<ul>
<li>Насколько большой рынок? (объём рынка)</li>
<li>Как вы будете снимать плату с пользователей? (модель монетизации)</li>
<li>Какие ключевые метрики следует отслеживать? (напрямую зависит от модели монетизации)</li>
</ul>
<p><strong>Преимущества</strong></p>
<ul>
<li>Какая у вас есть уникальная экспертиза?</li>
<li>Почему вы делаете то, что вы делаешь? (продемонстрируйте ваше глубокое понимание предметной области)</li>
</ul>
