11:T17a8,<h1>Фреймворки</h1>
<h3><strong>HEART FRAMEWORK</strong></h3>
<p>Позволяет отслеживать опыт пользователя (User Experience) по определённым категориям: счастье, вовлечённость, приятность, удержание, успех выполнения задач.</p>
<p>В него из коробки не входят прям конкретные метрики их нужно собирать под продукт. Тем не мнение это отличный гайд, который подойдёт для общих замеров и позволит перейти в плоскость данных.</p>
<p><strong>Happinnes</strong> — счастье отношение пользователя к продукту.</p>
<p>Примеры метрик:</p>
<ul>
<li>Удовлетворение пользователя (балл);</li>
<li>Лёгкость использования продукта (может быть количество кликов до целевого действия);</li>
<li>NPS (насколько готовы рекомендовать);</li>
<li>Настроение после использования;</li>
<li>Оценка пользователя.</li>
</ul>
<p><strong>Engagement</strong> — вовлечённость.</p>
<p>Уровень заинтересованности в продукте, начав пользоваться продуктом, пользователь продолжает это делать.</p>
<p>Примеры метрик:</p>
<ul>
<li>Частота визитов на сайт;</li>
<li>Длительность визитов;</li>
<li>Доля используемых продуктовых фич.</li>
</ul>
<p><strong>Addoption</strong> — принятие.</p>
<p>Использование продукта постепенно становится привычкой: клиент пользуется различными функциями продукта, ждёт выхода новых и рассказывает друзьям.</p>
<p>Примеры метрик:</p>
<ul>
<li>Сколько пользователей ставит новую версию программы;</li>
<li>Количество новых подписок;</li>
<li>Referral Rate.</li>
</ul>
<p><strong>Retention</strong> — удержание.</p>
<p>Метрики должны оценивать то, насколько пользователь продолжает пользоваться вашим продуктом.</p>
<p>Примеры метрик:</p>
<ul>
<li>Количество повторных покупок;</li>
<li>Активность пользователя на протяжении некоторого времени;</li>
<li>Retention Rate;</li>
<li>С2, С3 и.т.д</li>
</ul>
<p><strong>Task Success</strong> — успех.</p>
<p>Это технические показатели, такие как эффективность, производительность и количество ошибок.</p>
<p>Примеры метрик:</p>
<ul>
<li>Скорость загрузки фото на сайте;</li>
<li>Успешний поиск информации и др.</li>
</ul>
<p>Одна из основных проблем в коммуникации между бизнесом и дизайном в том, что крайне тяжело обосновать необходимость изменений и их положительное влияние на продук. <strong>Heart</strong> — гугловый фреймворк, который как раз позволяет оценить эффект.</p>
<h3><strong>FRAMEWORK AAARRR</strong></h3>
<p>Он представляет из себя воронку.</p>
<p><strong>Awareness (Информирование)</strong></p>
<ul>
<li>Описание: Знакомство клиента с продуктом. Например вход на сайт.</li>
</ul>
<p><strong>Acquisition (Привлечение)</strong></p>
<ul>
<li>Описание: Клиенту стало интересно и он оставил свои контакты.</li>
<li>Метрики: Количество заявок, установок, просмотров и.тд</li>
<li>Как улучшить: SEO оптимизация, расширение маркетинга.</li>
</ul>
<p><strong>Activation (Активация)</strong></p>
<ul>
<li>Описание: Клиент понял ценность продукта и стал им пользоваться.</li>
<li>Метрики: C0 (конверсия из заявки в ВУ, триал), SPS, Регистрация.</li>
<li>Как улучшить: Быстрая регистрация, улучшение качества 1-ой линии.</li>
</ul>
<p><strong>Retention (Удержание)</strong></p>
<ul>
<li>Описание: Клиент постоянно пользуется продуктом.</li>
<li>Метрики: Retention, MAU, Session, Frequency.</li>
<li>Как улучшить: Программы лояльности, коммуникация с клиентом, пуши, предложения для вернувшихся.</li>
</ul>
<p><strong>Referral (Виральность)</strong></p>
<ul>
<li>Описание: Клиент делится информацией о продукте.</li>
<li>Метрики: Referal Index, Sentiment, Analysis Rating, доля негатива, NPS.</li>
<li>Как улучшить: Реферальные программы, работа с комментариями.</li>
</ul>
<p><strong>Rrevenue (Доходность)</strong></p>
<ul>
<li>Описание: Клиент платит за продукт.</li>
<li>Метрики: ARPPU, LTV, Revenue.</li>
<li>Как улучшить: Развитие продукта, продаж, частота обновлений, багфиксинг.</li>
</ul>
