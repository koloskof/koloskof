11:T37cf,<h1>SQL</h1>
<p>Примеры: https://github.com/productstar-team/sql_course</p>
<p>Среда: <a href="https://sqliteonline.com/">https://sqliteonline.com/</a></p>
<p>С помощью SQL можно:</p>
<ul>
<li>Извлекать данные;</li>

<h2>Ключевые слова</h2>
<p>SELECT — слово для извлечения столбцов</p>
<p>FROM — ключевое слово для обозначения таблицы, из которой мы будем извлекать данные</p>
<p>Для извлечения данных мы пишем:</p>
<pre><code class="language-sql">SELECT что мы хотим (столбец/-цы)  FROM откуда мы хотим (таблица)
</code></pre>
<h2>Порядок ключевых слов</h2>
<ol>
<li>SELECT</li>
<li>FROM</li>
<li>WHERE</li>
<li>GROUP BY</li>
<li>HAVING ORDER</li>
<li>ORDER BY</li>
</ol>

<h2>Таким образом, типы данных нужно писать так</h2>
<p><strong>Числовой тип данных — число</strong></p>
<p>Пример: id = 1223 i~~d = ’1223’~~</p>
<p><strong>Числовой тип данных — ‘Текст’</strong></p>
<p>Пример: name = ‘Mary’ i~~d = Mary~~</p>
<p><strong>Тип данных с датой — ‘год-месяц-день’</strong></p>
<p>Пример: date = ‘2020-01-30’ date ~~= ’2030 30 01’ date=2020 01 30~~</p>

<h2>HAVING</h2>
<p>Ключевое слово для фильтрации сгруппированных значений</p>
<p>WHERE тоже используется для фильтрации значений.</p>
<p>Но WHERE не может быть использован для результатов группировок, а HAVING может.</p>
<p>Фильтрация сгруппированных значений HAVING</p>
<pre><code class="language-sql">SELECT
	column_name_1
	, MIN(column_name_2)
FROM
	table_name
GROUP BY
	column_name
HAVING
	condition()
</code></pre>
<pre><code class="language-sql">SELECT
	room_type
	, COUNT(*) AS
	total_count
FROM listings
GROUP BY
	room_type
HAVING
	total_count > 100
</code></pre>
<p>| room_type | total_count |
| --- | --- |
| Entire home/apt | 4435 |
| Private room | 4295 |
| Shared room | 147 |</p>
<p>Фильтрация сгруппированных значений HAVING</p>
<pre><code class="language-sql">SELECT
	column_name_1
	, MIN(column_name_2)
FROM
	table_name
GROUP BY
	column_name
HAVING
	condition(s) 
</code></pre>
<pre><code class="language-sql">SELECT
	room_type
	, COUNT(*) AS
	total_count
FROM listings
GROUP BY
	room_type
HAVING
	room_type !=
	'Shared_room'
</code></pre>
<p>| room_type | total_count |
| --- | --- |
| Entire home/apt | 4435 |
| Hotel room | 84 |
| Private room | 4295 |</p>
<h2>Порядок выполнения SQL-запросов</h2>
<p>Порядок выполнения ключевых запросов</p>
<ol>
<li>FROM</li>
<li>WHERE</li>
<li>GROUP BY</li>
<li>HAVING</li>
<li>SELECT</li>
<li>DISTINCT</li>
<li>ORDER BY</li>
<li>LIMIT</li>
</ol>
<p>Порядок написания</p>
<pre><code class="language-sql">SELECT
	category
	, COUNT(*) AS
	total_count
FROM movies
WHERE
	release_date >
	'2020-01-01'
GROUP BY
	category
HAVING
	total_count > 1
ORDER BY
	total_count DESC
</code></pre>
<h2>Разница между WHERE и HAVING</h2>
<p>WHERE — выбирает строки для группировки</p>
<p>HAVING — отбирает результаты для группировки</p>
<pre><code class="language-sql">SELECT
	room_type
	, COUNT(*) AS total_count
FROM listings
WHERE
	room_type != 'Hotel room'
GROUP BY
	room_type
HAVING
	total_count > 150
</code></pre>
