<h2>Списки</h2>

print(name[-1])
</code></pre>
<pre><code class="language-python">name = ['Кеша', 'Толик', 'Попугай']

for name in names:

name.append('Поругай')
print(names)

name.pop('Поругай')
print(names)

n = names.index('Толик')
print(n)

print(len(names))

letters.sort()
print(letters)

<h2>Кортежи и списки</h2>
<p>Кортеж представляет собой контейнер, который хранит упорядоченный контейнер. Кортеж отличается от списка тем, что он абсолютно не изменяемый.</p>
<pre><code class="language-python">tuple = ("first", 25, 25.1)
print(tuple)
</code></pre>
<p>Используя оператор list, кортеж можно превратить в список и наоборот с помощью оператора tuple(), список можно превратить в кортеж</p>
<pre><code class="language-python">print(list((45, 45, 147, 35))
print(tuple([45, 45, 147, 35]))
</code></pre>
<p>Списки представляют собой упорядоченные коллекции элементов. Они позволяют хранить в одном месте взаимосвязанные данные. Списки хороши тем, что внутри него можно хранить значения разных типов.</p>
<pre><code class="language-python">list = ["яблоко", "банан", "апельсин"]
</code></pre>
<h2>Словари</h2>
<p>Словари представляют собой коллекцию многих значений, но если в словарях/списках в качестве индекса у нас использовались порядковые номера, то в словарях в качестве индекса к какому либо элементу используется какой-то ключ. И этот ключ может быть абсолютно любого типа.</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
print(dict)
</code></pre>
<p>Найти длину списка можно с помощью функции len()</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
print(len(dict))
</code></pre>
<p>Для того чтобы вывести все ключи словаря, нужно использовать метод keys()</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
for k in dict.keys:
	print(k)
</code></pre>
<p>Для того чтобы вывести все ключи словаря, нужно использовать метод values()</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
for k in dict.values:
	print(k)
</code></pre>
<p>Для того чтобы вывести все ключи словаря, нужно использовать метод items()</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
for k in dict.items:
	print(k)
</code></pre>
<p>Для того чтобы обратиться к конкретному значения нашего словаря, нужно указать его ключ того значения, которое мы хотим вывести</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
print(dict["банан"])
</code></pre>
<p>Так же можно явно перезаписать значение у конкретного ключа</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
dict["банан"] = "зелёный"
print(dict)
</code></pre>
<p>Можно удалить какое-либо значения словаря. Для этого используется оператор del() и указывается имя словаря и ключ, который мы хотим удалить.</p>
<pre><code class="language-python">dict = {"яблоко": "красное", "банан": "жёлтый"}
del(dict["банан"])
print(dict)
</code></pre>
<h2><strong>Работа со строками</strong></h2>
<p>Текст заключенный в тройные кавычки может содержать в себе сколько угодно строк и выведется в операторе print() так как мы его записали в операторе принт</p>
<pre><code class="language-python">print("""dsjbdjs
sdsds
sdsd
sdd
s""")
</code></pre>
<p>С помощью /n можно перенести выведенный текст на отдельную строку</p>
<pre><code class="language-python">print('Привет\nПриветПривет')
</code></pre>
<p>Для вывода текста в кавычках нужно обернуть его апострофы, а для вывода его же в апострофах нужно обернуть его в кавычки</p>
<pre><code class="language-python">print('"Привет Привет Привет"')
print("'Привет Привет Привет'")
</code></pre>
<p>Для вывода части текста в кавычках нужно их экранировать, поставив перед ними слэш</p>
<pre><code class="language-python">print("Текст \"в\" кавычках")
</code></pre>
<p>Канкатенация строк позволяет их группировать и выводить вместе</p>
<pre><code class="language-python">text = "Привет"
text1 = "мир"
print(text + '' + text1)
</code></pre>
<p>Строки также можно перемножать для множественного вывода</p>
<pre><code class="language-python">text = "Привет"
print(text*5)
</code></pre>
<p>Списки как и строки являются иттерированными объектами,  поэтому у каждого символа есть порядковый номер, к которому можно обратиться</p>
<pre><code class="language-python">print(text[0])
print(text[0:3])
print(text[-1])
</code></pre>
<p>Методы для управления регистром</p>
<pre><code class="language-python">text = "Привет"
print(text.upper())
print(text.lower())
print(text.capitalize())
</code></pre>
<p>Метод split() позволят разбить строку на объекты внутри списка. В качестве аргумента передается передается символ, который будут являться разграничителем</p>
<pre><code class="language-python">text = "привет мир куда идёшь"
print(text.split("-"))
</code></pre>
<p>Метод join() позволяет вывести все элементы списка в строку с опраделенным разделителем</p>
<pre><code class="language-python">spisok = ["а", "b", "c"]
print(",".join(spisok))
</code></pre>
<p>Методы позволяют удалить пробелы в строке до первого символа/ до последнего символа отличные от пробела</p>
<pre><code class="language-python">text = "    sdjskdjks sdsd     "
print(text.strip())
print(text.lstrip())
print(text.rstrip())
</code></pre>
<p>Метод replace() позволяет удалить любой в строке на другой</p>
<pre><code class="language-python">text = "ololololololololo"
print(text.replace("l", "o"))
</code></pre>
