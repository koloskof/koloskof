11:T165d,<h1>Секция</h1>
<p>Figma: <a href="https://www.figma.com/file/3d3CsJ3OJQDW0dsdtoCEDZ/Templates?node-id=1%3A254">https://www.figma.com/file/3d3CsJ3OJQDW0dsdtoCEDZ/Templates?node-id=1%3A254</a></p>
<p>Является базой для разбивки всей контентной части страницы. Секция может использоваться как один раз, так и многократно в рамках одного экрана, при этом содержать одну или две области для наполнения содержимым. Если области две, то c помощь модификатора <code>structure</code> происходит управление их пропорциональным соотношение внутри.</p>
<p>Модификатор <code>space-vertical</code> позволяет управлять вертикальным отступом, горизонтальные же отступы вычисляются динамически, в зависимости от размера экрана и ширины контейнера.</p>

<h3>Элемент area</h3>
<p>Элемент <code>area</code> задаёт безопасные отступы по бокам, чтобы контент не прилипал к краям экрана. Размер отступов переопределяется в зависимости от ширины экрана.</p>
<p><a href="%D0%A1%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%20a97e92205fc749fcad4fdc3d997025a5/%D0%9C%D0%BE%D0%B4%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80%D1%8B%204061025cf1f444b59a4d0b6d561301de.csv">Модификаторы </a></p>
<p><img src="sectionGhost.png" alt="%D0%A1%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%20a97e92205fc749fcad4fdc3d997025a5/sectionGhost.png"></p>
<pre><code class="language-json"> {
  block: 'tpl-section',
  mods: { structure: '50-50', size: 'l', 'space-v': 'half' },
  content: [
    {
      elem: 'area',
      elemMods: { view: 'ghost' },
      content: {
        elem: 'container',
        content: [ ... ]
      }
    },
    {

    }

<p>В большинстве случаев нам нужно ограничить ширину контента, для этого используется элемент container, который располагается по центру экрана. Он принимает нужную ширину в зависимости от модификатора <code>size</code> у родителя. Пропорциональная разбивка производится с учётом контейнернной ширины. Остальная же часть пространства от границы контейнера до краёв экрана в равной пропорции, расходуется на внутренние боковые отступы по краям экрана.</p>

<p>Если ширина экрана меньше ширины контейнера, то он сжимается под ширину экрана минус безопасные отступы по бокам.</p>
